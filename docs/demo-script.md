# Two-minute demonstration

0–20 seconds. Introduce a research assistant that reads reports and retains useful facts across tasks. Show one clean fact saved.

20–45 seconds. Open a report that embeds a reconciliation preference. Inspect its provenance and the attempted memory update. Show the paid assessment and its actual receipt when a verified purchase is available. Label unavailable integration honestly.

45–70 seconds. Advance the replay clock by three days. A later task proposes a transfer to the planted recipient. Show that the deterministic approval boundary denies it.

70–95 seconds. Trace the source through derived memories. Preview descendant quarantine, apply recovery, and show an unrelated valid memory surviving. Demonstrate reversible recovery separately.

95–115 seconds. Complete a legitimate approved simulation. Show benchmark raw counts, false positives, costs, and limitations.

115–120 seconds. Point reviewers to setup instructions, SDK entry points, the frozen dataset, and independently inspectable evidence.
